# Tech Specs

Mỗi feature mới → 1 file `<feature>.md` ở đây TRƯỚC khi code.

Template:
- **Mục tiêu**: 1-2 câu feature làm gì.
- **Yêu cầu**: checklist [ ] các điều kiện phải đạt.
- **Ràng buộc**: giới hạn kỹ thuật/bảo mật bắt buộc.
- **Quyết định**: chọn gì, vì sao (chống hỏi lại).
- **Ngoài phạm vi**: cái KHÔNG làm ở phiên này.

## Recommendation

- [Cá nhân hóa gợi ý bằng hành vi](Recommendation_Behavior.md): trọng số, cập nhật hồ sơ, trạng thái API và hướng dẫn kiểm tra.
- [Bàn giao backend gợi ý](Recommendation_Handoff.md): đọc sau khi merge; cấu hình, ý nghĩa hai collection MongoDB, API cho frontend và checklist tích hợp.
